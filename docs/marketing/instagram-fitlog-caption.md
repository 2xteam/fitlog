다시 진단을 받고 나서야 생각했습니다.
체중을 줄이고, 몸을 제대로 관리해야겠다고.

4월부터 지금까지 11kg을 감량했습니다.
그 과정에서 인바디와 피검사 수치를 기록으로 남기고,
벗어난 수치에 대한 권고를 매번 검색하지 않고도 알 수 있으면 좋겠다는 생각으로 FitLog를 만들었습니다.

결과지를 찍으면 인쇄된 항목을 모두 읽어 날짜별로 쌓아 두고,
적정 범위를 벗어난 항목에는 근거를 밝힌 권장사항이 붙습니다.
진단이나 처방은 하지 않아요. 기록을 읽고 생활 습관을 안내하는 데까지입니다.

저처럼 몸의 변화를 추적하고 싶은 분들께 무료로 공개합니다.

## 다듬은 기준

- 시간 순서대로: 시술 → 14년 → 올해 초 → 진단 → 감량 → 만든 이유 → 공개
- 한 문장에 한 가지. "그후로 다시 진단을 받고, 체중을 줄이고 건강 관리에도…" 를 둘로 나눴다
- 서비스 설명은 소개 페이지 문장 그대로(찍으면 읽어 쌓는다 · 근거를 밝힌 권장사항). 진단·처방을 하지 않는다는 문장을 넣었다 — 건강 앱 소개에는 반드시 필요하다
